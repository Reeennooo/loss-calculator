# Калькулятор потерь на заявках

Статическая страница без бэкенда и сборки.

- `index.html`, `styles.css`, `app.js`: страница
- `calc.js`: формулы и валидация
- `calc.test.mjs`: проверка по контрольным цифрам из ролика (`npm test`)

## Локально

```sh
npm start   # http://localhost:8080
```

Нужен именно HTTP-сервер: ES-модули не грузятся по `file://`.

## Ссылка на ассистента

Ссылка собирается в `chatLink` в `app.js`: кнопка открывает `https://t.me/renat_username?text=Ренат, привет! Посчитал в калькуляторе, получилось ~540 000 ₽ в месяц. Хочу аудит заявок по моей компании 📊`. Подстановку текста в чат с личным аккаунтом нужно проверить на телефоне. Если текст не подставится, кнопка всё равно откроет чат, а под ней есть подсказка написать «аудит» и сумму.

## Деплой

Залить папку на любой статический хостинг: Vercel, GitHub Pages (Settings → Pages → ветка `main`, корень), свой домен.
